


# Speech Emotion Recognition Using Deep Learning
A deep learning-based speech emotion recognition system using audio signal processing, feature extraction, and CNN-LSTM models.

## Created by
**Maira Asim**

## Project Overview

This project focuses on recognizing human emotions from speech audio using deep learning and speech signal processing techniques.

The model is trained on the RAVDESS speech emotion dataset and uses MFCC features to classify emotions from audio files.

## Objective

The objective of this project is to classify speech audio into different human emotion categories, such as:

- Angry
- Calm
- Disgust
- Fearful
- Happy
- Neutral
- Sad
- Surprised
